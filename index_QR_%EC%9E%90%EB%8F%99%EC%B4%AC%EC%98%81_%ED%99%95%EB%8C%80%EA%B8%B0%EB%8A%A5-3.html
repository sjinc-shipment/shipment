2. 계속 찍기

카메라 시작을 누르면 여기에 촬영 화면이 나와요.
1.0배
납품서 번호 입력 → 카메라 시작 → 코드 인식 시 자동 촬영

QR/바코드를 인식하면 초록색 사각형을 표시하고 자동 촬영해요. 확대 슬라이더를 움직이면 촬영 사진과 코드 인식도 같은 비율로 확대돼요. 같은 코드가 화면에 계속 있는 동안에는 중복 촬영하지 않아요. 코드가 없는 사진은 촬영 버튼으로 직접 찍을 수 있어요.

시험판 안내

이 파일은 기존 출하관리 파일과 별개예요. 카메라가 열리지 않으면 카메라 권한을 허용하고 크롬에서 열어 보세요. 일부 휴대폰은 로컬 HTML 카메라 사용이 제한되어 HTTPS 웹사이트가 필요할 수 있어요. QR/바코드 인식은 브라우저 지원 또는 인터넷 연결(CDN)에 따라 달라질 수 있어요. 자동 촬영이 지원되지 않아도 수동 촬영 버튼을 사용할 수 있어요.
